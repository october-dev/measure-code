This is a full co-op action game client, not a prototype: 14 people put 9,400 commits into it between 2019 and 2024.
Under the hood it runs a deterministic simulation with procedural levels and networked play, which is the hard kind of game code to get right.
The team cared about craft, with 1,260 test cases, 37 release tags and 1,034 merged pull requests behind it.
All 165,900 lines were written before 2025, so this is years of human game-making, not a weekend of generated code.
